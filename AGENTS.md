# Agent Instructions

## Project Overview
This repo documents and develops AgentFrame — a structured approach to project creation and maintenance using AI agents.

## Structure
- `docs/` — Published documentation (human-first).
- `.agent-data/` — Agent working memory (agent-first).
- `README.md` — Human quick-start.

## Conventions
- All docs in `docs/` are human-first.
- `.agent-data/` is agent-first working memory.
- Keep files under 300 lines for agent readability.

## Git Workflow
- Tracked: `docs/`, `.agent-data/context.md`, `.agent-data/decisions.md`, `.agent-data/plans/`, `.agent-data/scripts/`
- Ignored: `.agent-data/scratch/`, editor junk
