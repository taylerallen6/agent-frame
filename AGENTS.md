# Agent Instructions

## Project Overview
This repo documents and develops AgentFrame — a structured approach to project creation and maintenance using AI agents.

## Structure
- `docs/` — Published documentation (human-first).
- `.agentframe/` — Agent working memory (agent-first).
- `README.md` — Human quick-start.

## Conventions
- All docs in `docs/` are human-first.
- `.agentframe/` is agent-first working memory.
- Keep files under 300 lines for agent readability.

## Git Workflow
- Tracked: `docs/`, `.agentframe/context.md`, `.agentframe/decisions.md`, `.agentframe/plans/`, `.agentframe/scripts/`
- Ignored: `.agentframe/scratch/`, editor junk
