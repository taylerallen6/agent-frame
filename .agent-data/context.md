# Agent Project System

A structured approach to project creation and maintenance using AI agents.

## Goals
- Define a standard project structure for AI-assisted development
- Create reusable skills for planning, decision-making, and documentation
- Keep agent working memory separate from published documentation

## Tech Stack
- Markdown for all documentation
- Git for version control
- Hermes Agent Skills for workflows

## Current Focus
Building out the initial repo structure and skill definitions.
